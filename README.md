# Hady Sleam portfolio

Personal portfolio, built with React, TypeScript and Vite. English and Arabic.

    npm ci
    npm run dev
    npm run build

## Images

Portrait and project images are stored as base64 text in `assets/images/*.b64` and restored to `public/images` by the deploy workflow before the build. For local development, run the same decode step or copy the original JPEG files into `public/images`.
