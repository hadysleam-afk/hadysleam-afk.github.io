Background & Philosophy

Real backends. Honest demos.

I study Physics and Computer Science at the Faculty of Science, and I build web applications on the side. Physics taught me to model how things actually behave; computer science gave me the tools to build those models into working software.

My interest is the backend: APIs, databases and the services behind the screen. A dashboard that shows real data is engineering. A dashboard that only looks like it does is decoration. I build the first kind, and I say clearly when something is a demo.

"A good interface earns attention. A good backend earns trust."

My most complete project is SolarMind, a solar monitoring and inspection platform with a database, API documentation and a dashboard on top. Alongside it I build interfaces: business sites, dashboards and management systems.
